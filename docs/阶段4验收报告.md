## 5. 用户实测反馈修复记录（三轮）

### 5.1 框选跳到最上/最下（第 1 轮）
- 现象：全选后上下移动鼠标，列表直接跳到最上/最下
- 根因：选中项触发 BringIntoView，虚拟化面板按估算位置滚动
- 修复：程序化批量选中期间压制 BringIntoView

### 5.2 框外文件选不上（第 2 轮）
- 现象：框选只能选窗口内文件；从最下面往上拖列表跳顶
- 根因：① 无自动滚动；② 像素偏移滚动被面板"锚点纠偏"，上滚 711→0 一步跳顶；③ 按可见容器判定会漏掉跳变区间
- 修复：① 边界外自动滚动；② 滚动改为按整行滚入（ScrollIntoView 走面板自身定位逻辑）；③ 选中判定改为文档坐标算术（几何中位数测量 + 自检，失效时退化为容器判定）

### 5.3 卡片不显示缩略图（第 3 轮）
- 现象：文件只有悬浮框里有画面，卡片只有占位文字
- 根因：**双重扩展名** —— DB 存 `hash.jpg`，显示时 `ThumbAbsolutePath` 再拼一次 `.jpg` → `hash.jpg.jpg` 永远不存在
- 修复：`ThumbAbsolutePath` 容错（带 .jpg 就不重复拼）；验证 `ThumbPath=…jpg → …jpg | 存在=True | 解码=成功`；另修复批量重命名对瞬时占用文件的重试（5 次 × 250ms）

### 5.4 框选第三轮反馈（框选取消/框消失/底行拖不动/FLAC 播放）

| 反馈 | 根因 | 修复 |
|---|---|---|
| 框选超出窗口后"自动取消框选"、选框消失 | ① 选框超出列表边界被 ClipToBounds 裁剪不可见；② 光标在边界外时滚动跳变导致文档坐标瞬间失真，误删已选中的项 | 去掉裁剪（选框可延伸显示）；**光标在边界外时"只加不减"**——选框只朝拖动方向扩张，已选中的项绝不会被误取消 |
| 从最底下一行往上拖无法框选 | 框选只在空白处按下才启动，按在卡片上被 ListBox 当普通选择 | 重构：**按下不拦截，拖动超过 3px 才接管为框选**——从卡片上、从空白处都能框选；单击/双击不受影响 |
| 上拖又出现跳顶 | 虚拟化面板对"向上程序滚动"顽固反抗（滚一步拽回一步，最后弹到远处 1017→1611） | **向上拖不再滚动列表**：列表纹丝不动，选框按文档坐标向上扩张，窗口外文件照样全选（稳定优先，零跳变）；向下拖保留自动滚动 + 跳变回抽检测回滚 |
| 可见行的边缘项漏选（几何漂移） | 文档坐标算术对屏内项有像素级漂移 | **混合判定**：可见卡片按真实边界精确判定，屏幕外的才用算术近似 |
| FLAC 转码后播放不了 | 双击依赖系统默认程序，系统无 FLAC 关联即失败 | **双击视频/音频改为内置播放器（VLC）固定放大播放**，不依赖系统；照片仍走系统看图工具；系统打开失败时弹"选择打开方式" |

### 5.5 框选第四轮反馈（从下往上框选，中间部分被取消）

- 现象：从最下往上框选时，选框扫过的**中间部分**被取消选中
- 根因：选框随光标回移而缩小，缩小区域的项被"移除"逻辑取消；估算几何的像素漂移又会把框内项误判为框外
- 修复：框选改为**纯累加**语义 —— 选框扫过的立即选中，光标回移/选框缩小**绝不取消**（取消只交给：新一次框选、点击空白处、取消选择按钮）；可见卡片按真实边界判定、屏幕外按文档坐标算术
- 验证：诊断新增"拖出顶部后把光标移回列表中间"断言 —— 移回前 8 项 → 移回后 8 项（不减少）

### 5.6 框选第五轮反馈（超出窗口的选中"有几率"被取消 + 拖出文件 + 右键太淡）

| 反馈 | 根因（源码级定位） | 修复 |
|---|---|---|
| 从最下框选到最上时列表跳顶、选中数波动 | **WPF ListBox 源码实锤**：`OnIsMouseCapturedChanged` —— 列表被鼠标捕获时启动内部 `_autoScrollTimer`，其 Tick 调 `DoAutoScroll` → 鼠标在列表上方时 `NavigateToStart` → **滚到顶部**。框选接管恰好捕获了 ListBox 本身 → 定时器必然启动 | 捕获后立即反射停掉该定时器；按下期间的**所有**鼠标移动全部拦截（堵住启动路径）；自建 `MarqueeListBox` 抑制"滚到选中项" |
| 中间部分被取消 | 选框随光标回移缩小 + 移除逻辑 | 框选改**纯累加**：扫过的绝不取消（取消只交给：新框选/点击空白/取消按钮） |
| 无法把文件拖出到别处 | 未实现 | **卡片上按住拖动 = 拖出文件**（复制到目标，库内原件不动；按下的卡片在选中集内则拖出全部选中）；空白处拖动 = 框选 |
| 右键文字太淡 | 未定制 ContextMenu 主题 | 深色菜单样式：深底 + 亮字 + 高亮项 |
